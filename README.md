## 어려웠던 점 3가지와 해결

1. 화면 크기에 따라 카드의 배치를 조절 하는 부분이 시간이 꽤 걸렸던 것 같습니다.

   계속해서 시도하며 맞는 값을 찾아냈습니다.

2. 아무래도 한 코드내에서 하는 것이아니라 index.html, style.css, detail.html을 동시에 구현해야 하다보니 중간중간 혼동이 오는 경우가    많았던 것 같습니다.

   헷갈릴때 마다 교수님이 주신 ppt를 다시보며 다시 시도하였습니다

3. 보너스 부분의 스켈레톤과 다크,라이트 모드를 구현하는 과정에서 처음 접하는 부분이라 구현하는데 어려움이 있었습니다.
   
   AI에게 질문하여 스켈레톤과 다크 라이트 모드의 개념을 공부해보았고 그 중 스켈레톤 구현은 이해가 되지 않아 힘들것같아 포기하고  다크라이트 모드만 구현하였습니다.
